# Tip Calculator

Splits a bill and tip between any number of people.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/tip-calculator.git
```
